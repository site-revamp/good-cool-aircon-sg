# GoodCool SG Homepage Redesign

## Website Overview

GoodCool SG provides aircon servicing, chemical cleaning, repairs, installation, and maintenance contracts for homes and businesses in Singapore. The proposed homepage helps visitors choose a service, understand what the price covers, and book an appointment.

## Main Improvements

1. **Lead with a specific customer benefit.** Replace repeated promotional claims with an opening headline and short summary that explain how GoodCool helps customers with routine maintenance, repairs, or installation and where they can find published package prices.
2. **Bring service scope and pricing together.** The current homepage sends visitors to different pages for package prices and service details. Use a consistent layout to show who each option suits, what the work includes, and what the published price covers. Distinguish one-time services from maintenance contracts.
3. **Give visitors a clear route to booking.** Multiple booking labels and destinations make the next step unclear. Place relevant booking links beside service and package summaries, and use a consistent appointment button label for the online booking page.

## Design Improvements

A focused hero, consistent service cards, and clear headings would make the homepage easier to scan. Placing price details and booking actions beside each option would help customers compare services and act from the same section.
